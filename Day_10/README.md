# 🔐 Day 10 - Secret Message Encrypter & Decrypter

## 📌 Project Description

The **Secret Message Encrypter & Decrypter** is a Python application that allows users to securely encrypt and decrypt text messages using a simple encryption technique. It demonstrates how text can be transformed into encoded data and restored back to its original form.

---

## 🚀 Features

- 🔒 Encrypts secret messages.
- 🔓 Decrypts encrypted messages.
- 📝 Accepts custom user input.
- 🔄 Converts messages using encryption logic.
- 🖥️ Beginner-friendly command-line interface.

---

- Conditional Statements
- Functions
- String Manipulation
- Character Encoding
- User Input
