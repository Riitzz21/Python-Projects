# 💖 Day 11 - Friendship Compatibility Calculator

## 📌 Project Description

The **Friendship Compatibility Calculator** is a fun Python application that calculates a friendship compatibility score based on the names entered by the user. The program generates a compatibility percentage and displays a friendly message based on the result.

---

## 🚀 Features

- 👥 Accepts two names as input.
- 📊 Calculates a friendship compatibility score.
- 💬 Displays a personalized compatibility message.
- 🎉 Interactive and beginner-friendly terminal application.
- 🖥️ Simple command-line interface.
