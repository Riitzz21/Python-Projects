# 🌦️ Day 04 - Real-Time Weather Logger (API + CSV)

## 📌 Project Description

The **Real-Time Weather Logger** is a Python application that retrieves current weather information using a weather API and stores the collected data in a CSV file.

The project demonstrates how Python can work with external APIs, process JSON responses, and maintain a historical weather log using CSV data storage.

---

## 🚀 Features

- 🌍 Fetches real-time weather information using an API
- 🌡️ Retrieves temperature and weather conditions
- 💨 Collects additional weather information
- 📊 Processes API response data
- 💾 Stores weather records in a CSV file
- 📅 Maintains a history of collected weather data
- 🖥️ Simple command-line interface

## 🔄 How It Works

```text
User enters location
        ↓
Python sends API request
        ↓
Weather API returns JSON data
        ↓
Program extracts required information
        ↓
Weather data is displayed
        ↓
Data is stored in CSV
```

---

## 📊 Data Stored

The CSV file can contain information such as:

| Date/Time | City | Temperature | Weather |
|-----------|------|-------------|---------|
| Timestamp | City Name | Temperature | Condition |

This allows multiple weather records to be stored and reviewed later.
