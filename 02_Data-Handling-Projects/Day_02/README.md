# 📊 Day 02 - Student Marks Analyzer

## 📌 Project Description

The **Student Marks Analyzer** is a Python command-line application that collects student names and their marks, then analyzes the data to generate a simple marks report.

The program calculates the average marks, identifies the student(s) with the highest and lowest marks, and displays a detailed report of all students.

---

## 🚀 Features

- 👨‍🎓 Collects student names and marks
- 📊 Calculates average marks
- 🏆 Finds the highest marks and topper
- 📉 Finds the lowest marks
- 📋 Displays all student marks
- 🚫 Prevents duplicate student names
- ❌ Validates marks input
- 🖥️ Provides a simple command-line interface

## 📊 Analysis Performed

The program analyzes:

| Analysis | Description |
|----------|-------------|
| Total Students | Counts the number of students |
| Average Marks | Calculates the class average |
| Highest Marks | Finds the highest score |
| Topper | Identifies the student(s) with the highest score |
| Lowest Marks | Finds the lowest score |
| Detailed Report | Displays every student's marks |
