# 📇 Day 01 - CLI Contact Book (CSV Powered)

## 📌 Project Description

The **CLI Contact Book (CSV Powered)** is a Python command-line application that allows users to manage their contacts using a CSV file as a simple data store.

The application provides options to add, view, search, update, and delete contacts. Contact information such as names, phone numbers, and email addresses is stored and managed through CSV file handling.

---

## 🚀 Features

- ➕ Add new contacts
- 📋 View saved contacts
- 🔍 Search for contacts
- ✏️ Update existing contact information
- 🗑️ Delete contacts
- 💾 Store contact data in a CSV file
- 🚫 Prevent duplicate contact names
- 🖥️ Simple command-line interface

## 📊 Data Handling

The project uses a CSV file to store contact information.

Example:

```csv
Name,Phone,Email
Rajeshwari,9876543210,raj@example.com
Aman,9876543211,aman@example.com
Neha,9876543212,neha@example.com
```

The CSV file allows the program to save and retrieve contact information even after the program is closed.
