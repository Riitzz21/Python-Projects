# 🎬 Day 03 - Personal Movie Tracker with JSON

## 📌 Project Description

The **Personal Movie Tracker with JSON** is a Python command-line application that allows users to maintain and manage a personal collection of movies.

The application stores movie information in a JSON file, allowing data to remain available even after the program is closed.

---

## 🚀 Features

- ➕ Add movies to the collection
- 📋 View saved movies
- 🔍 Search for movies
- ✏️ Update movie information
- 🗑️ Delete movies
- 💾 Store movie data using JSON
- 📂 Load previously saved movie data
- 🖥️ Simple command-line interface

## 📦 Data Storage

Movie information is stored in a JSON file.

Example:

```json
[
    {
        "title": "Inception",
        "year": 2010,
        "rating": 8.8
    },
    {
        "title": "Interstellar",
        "year": 2014,
        "rating": 8.7
    }
]
```

JSON provides a convenient way to store structured data that can be loaded and modified by the Python program.
